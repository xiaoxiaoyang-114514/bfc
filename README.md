# bfc

用 Rust 实现的 [Brainfuck](https://en.wikipedia.org/wiki/Brainfuck) 编译器。

`bfc` 将 Brainfuck 源码逐条翻译为等价的 Rust 代码，并通过 `rustc` 将其编译为本地可执行文件。

## 使用方法

```bash
cargo run -- <程序.bf>
```

运行后会在当前目录生成：

- `<程序>.rs` —— 翻译后的 Rust 源码
- `<程序>` —— 编译出的可执行文件

## 示例

`hello.bf`：

```brainfuck
++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
```

编译并运行：

```bash
cargo run -- hello.bf
./hello
```

## 支持的指令

| 指令 | 含义 |
| ---- | ---- |
| `>` | 指针右移一位，必要时扩充内存 |
| `<` | 指针左移一位（移出边界时崩溃） |
| `+` | 当前单元格加一（循环回绕） |
| `-` | 当前单元格减一（循环回绕） |
| `.` | 将当前单元格作为字符输出 |
| `,` | 从标准输入读取一个字节存入当前单元格（文件末尾时为 0） |
| `[` | 若当前单元格为 0 则跳转到匹配的 `]` 之后 |
| `]` | 若当前单元格不为 0 则跳转回匹配的 `[` |

## 工作原理

1. 读取 `.bf` 源文件
2. 将其逐字节翻译为 Rust 代码（`src/lib.rs` 中的 `bfrs` 函数）
3. 写出 `<程序>.rs`
4. 调用 `rustc` 编译生成可执行文件

## 构建

```bash
cargo build --release
```
